## The entry

One image that sums up Tuesday 24 November 2026: 35 verified stories across
7 regions (Africa, Asia, Europe, Middle East, North America, South America,
Oceania — 5 each), led by Ukraine's sea drones sinking the Russian corvette
Merkury off Benghazi, Libya. Every story is illustrated; the date is named
prominently.

`main.py` copies the finished image (`entry.png`, 1024×1024) to
`/output/entry.png`. Standard library only, no network, deterministic.
